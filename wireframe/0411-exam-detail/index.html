One page: head, run card (info row + run bar), action row, students. The student display is a toggle above the students.

Control flow

  • Five surface states over three internal ones. OPEN, LIVE and OVERTIME are all internally LIVE, so monitoring works in all three.
  • One button per state: OPEN NOW (transition) → START NOW (writes the actual start, no transition) → END EXAM (transition).
  • Primary vs secondary: one filled primary per state — the thing the teacher is here to do — everything else on the raised neutral, destructive actions quiet at the far end.

Extend

  • A native time picker holding the new end, pre-filled with the current one, joined to an EXTEND button. The teacher sets when the exam finishes instead of doing arithmetic on an offset.
  • It moves the scheduled end. Once the clock passes that end the exam shows OVERTIME; setting a later end pulls it back to LIVE.

Students

  • A tile only says something when something is wrong — No signal. A healthy stream is just the stream. Every student has a recording afterwards.

Overtime on the bar

  • The scheduled end stops being the end of the track: the bar runs past it in purple, and the marker is relabelled "Scheduled end".
