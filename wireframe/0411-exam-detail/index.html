Safe option: the dashboard's width rule — one centred 1300px container, main column plus a 300px widget column.

Layout

  • PIN leads the title line, plain monospace, no box, one colour in every state.
  • Title edit is a pencil icon button at the title, available in every state.
  • Metadata lives in the DETAILS widget; the CONTROL widget holds actions only, no sentences.

Control flow

  • Three internal states — SCHEDULED, LIVE, ENDED — shown as five on the surface: SCHEDULED, OPEN, LIVE, OVERTIME, ENDED. OPEN, LIVE and OVERTIME are all internally LIVE.
  • One button per state: open now (transition) → start now (sets the actual start, no transition) → end exam (transition).
  • Monitoring runs wherever the exam is internally live. Full edit only while SCHEDULED. Title edit and delete always.

Control flow

  • Five surface states over three internal ones. OPEN, LIVE and OVERTIME are all internally LIVE, so monitoring works in all three.
  • One button per state: OPEN NOW (transition) → START NOW (writes the actual start, no transition) → END EXAM (transition).
  • Primary vs secondary is load-bearing and carries into the design step: one filled primary per state — the thing the teacher is here to do — everything else outlined, destructive actions quiet at the far end.

Extend

  • EXTEND TO plus a native time picker holding the new end, pre-filled with the current one. The teacher reads and sets the thing they actually care about — when the exam finishes — instead of doing arithmetic on an offset. Typing, arrow keys, the browser's own clock popup and screen-reader support all come from <input type="time">; step="300" keeps it on 5-minute marks.
  • It moves the scheduled end. Once the clock passes that end the exam shows OVERTIME; setting a later end pulls it back to LIVE.

Info vs actions

  • The action row holds controls only. Every sentence moved to the info row between the bar and the actions.

Overtime on the bar

  • The scheduled end stops being the end of the track: the bar runs past it, the overshoot is hatched, and the marker is relabelled "Scheduled end". Purple in the design step.
