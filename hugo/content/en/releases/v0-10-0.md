[GitHub Release](https://github.com/2526-4ahitm-itp/2526-4ahitm-franklyn/releases/tag/v0.10.0)

Exams with many students and several teachers watching at the same time now stay smooth.

## Features

### New Recorder

Sentinel's screen recorder was rewritten. Recording is more stable on Windows, macOS, X11 and Wayland, and when something breaks Sentinel now reports the actual cause instead of a vague error.

### Windows Installer

The Windows installer is a setup wizard now. Students download it, double click it and click through the installation.

## Improvements

- A Proctor that can't keep up no longer slows down the other Proctors. The server skips frames for it instead.
- The server frees the screens of students that left, so it stays fast during long exams.
- The portable install now also works on distributions without zstd, like Rocky and Alma Linux.

## Docs

- Every supported system has its own installation page, in English and German.
- Every installation page has an uninstall section.
