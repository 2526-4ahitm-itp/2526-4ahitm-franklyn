## 1. Installieren

Lade den Installer herunter, doppelklicke ihn und folge dem Installationsassistenten.

<div class="download-button">{{< hextra/hero-button text="Für Windows herunterladen" link="https://github.com/2526-4ahitm-itp/2526-4ahitm-franklyn/releases/latest/download/franklyn-sentinel-x86_64-windows-setup.exe" >}}</div>

{{< callout type="warning" >}}
Wenn eine Windows-Sicherheitswarnung erscheint, klicke auf „Weitere Informationen“ und „Trotzdem ausführen“.
{{< /callout >}}

## 2. Einer Prüfung beitreten

Öffne ein Terminal und führe aus:

```shell
franklyn join <pin>
```

## Aktualisieren

Lade den neuesten Installer herunter und führe ihn erneut aus.
